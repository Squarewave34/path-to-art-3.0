# Project Brief

## Project overview
    Path to art is a productivity software that aims to organize artists' creative process by allowing them to save details of their projects in one place. 
## Project Description
    We need to create a fully functional productivity software that works online with a proper responsive design.
## Target audience
    Artists of all ages! but especially busy digital artists who like to keep their art schedule busy all year long!
## Project scope
    We'll be making a software similar to Microsoft to do with multiple pages and a lot of functionality.
## Key desired attributes and emotions
    Vibrant, inspiring, creative
